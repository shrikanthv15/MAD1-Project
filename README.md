# MAD1 Project Admin Portal

A lightweight Flask-based admin portal focused on login and venue management. The app provides an admin login flow, an admin dashboard, and a page for adding venues. It uses Flask, SQLAlchemy, and common Flask extensions to enable templating, forms, authentication, and migrations.

## Getting Started / How to Run

The repository includes a requirements file that you can use to install the dependencies. Below are concrete steps based on the actual config files present.

1) Create and activate a virtual environment (optional but recommended)
- Unix/macOS:
  - python3 -m venv venv
  - source venv/bin/activate
- Windows:
  - python -m venv venv
  - venv\Scripts\activate

2) Install dependencies
- pip install -r requirements.txt

3) Run the application
- Since the repo does not include explicit run scripts, you can use Flask’s standard CLI approach or run the app module directly if configured:
  - Using Flask CLI (preferred for Flask apps):
    - export FLASK_APP=main
    - export FLASK_ENV=development
    - flask run
  - Windows:
    - set FLASK_APP=main
    - set FLASK_ENV=development
    - flask run
  - Direct execution (if main.py is set up to run the app):
    - python main.py

Notes:
- The code defines a Flask app in main.py and uses templates for the UI.
- If you need to customize the environment (development vs production), adjust FLASK_ENV accordingly.

## Project Structure

- __pycache__/: Compiled Python bytecode caches.
- templates/: HTML templates for the UI
  - addvenue.html: Venue addition form
  - admin_login.html: Admin login form
  - baseadmin.html: Base admin template
  - navbar.html: Navigation bar
  - new.html: Placeholder/new admin page
- virt/: A local virtual environment snapshot containing site-packages and Python runtime (vendored dependencies).
- admin.db: Admin-related database file (SQLite)
- adminDB.db: Main application database (used by SQLAlchemy in main.py)
- db/: Directory for database-related artifacts (examples may appear as part of migrations)
- main.py: The Flask application with routes for admin login, dashboard, and venue management
- insertAdmin.py: Script likely used to insert an admin user (as seen in repo)
- freeze/: Likely placeholder for dependencies or environment freezing artifacts
- requirements.txt: Exact Python dependencies and versions used by the project
- tempCodeRunnerFile.py: Temporary helper script (likely auto-generated by IDE)
